Privacy Policy

Application: RESTdrop • App ID: com.iembed8.restdrop • Last Updated: September 13, 2026 Zero Cloud Telemetry

Privacy Commitment: RESTdrop operates entirely on your local device. We do not collect, harvest, monitor, sell, or transmit any personal information, browsing data, hardware telemetry, or API payloads to any external servers.

1. Summary & Core Promise

This Privacy Statement explains how RESTdrop ("we", "us", "our", or "the Application"), developed by Manav Akela / iEmbed8, handles information when you install and run the desktop application on Microsoft Windows or other supported operating systems.

RESTdrop is a local developer tool designed to bridge HTTP / HTTPS REST API calls directly to hardware Serial (COM / TTY) ports. All networking, routing, data formatting, and logging are executed 100% locally on your machine.

2. Information We Do Not Collect

Unlike web services or cloud-connected apps, RESTdrop does not maintain accounts or cloud backends. Specifically:

  • No Personal Identifiable Information (PII): We do not collect names, email addresses, phone numbers, IP addresses, physical locations, or device identifiers.
  • No Payload Inspection: We do not inspect, upload, or transmit any HTTP/HTTPS request bodies, path parameters, query variables, or serial stream data sent through your configured instances.
  • No Account Credentials: RESTdrop requires no user login, credentials, or third-party authentication.
  • No Cookies or Tracking: No tracking cookies, web beacons, advertising SDKs, or third-party fingerprinting scripts are bundled or loaded.

3. Local Data & Storage

Any data processed by RESTdrop remains strictly on your local machine within the standard application data directory. Here is what is stored locally:

Data Type Local Path / Storage Purpose & Retention
Configuration %APPDATA%\com.iembed8.restdrop\restdrop_config.json Stores your custom port numbers, endpoints, baud rates, and serial formatting settings. Retained until you delete or uninstall the app.
Traffic Logs Volatile Memory (RAM) Real-time request logs shown in the Traffic Monitor tab are held strictly in memory and cleared upon application restart or manual clear.
UI Settings Browser localStorage Stores local UI preferences (Dark/Light theme, accent color, panel toggles).

You may inspect, backup, or delete any of these files at any time via the Settings modal or by deleting the directory directly in Windows File Explorer.

4. Hardware & Network Access Permissions

To perform its core functions as an embedded REST-to-Serial bridge, RESTdrop requests and utilizes the following local system capabilities:

  • Local Network Binding: Binds to local loopback addresses (such as 127.0.0.1, localhost, or 0.0.0.0) on user-selected ports (e.g., 3000) to receive your API test requests. The application does not initiate outbound Internet connections.
  • Serial (COM) Port Access: Connects to physical or virtual serial devices (e.g., COM1, COM3, /dev/ttyUSB0) attached to your machine to transmit and receive test data.
  • Local File System: Reads and writes local configuration files within your user profile directory.
  • Windows Startup (Run Registry): If enabled, registers an autostart entry in HKCU\Software\Microsoft\Windows\CurrentVersion\Run so the background service can run minimized to your taskbar on system logon.

5. Telemetry & Third-Party Services

RESTdrop contains no telemetry code, crash reporting analytics (e.g., Sentry, Google Analytics), or marketing trackers. When you run RESTdrop, zero network packets are sent to the developer or any third party.

If you download RESTdrop from the Microsoft Store, Microsoft may collect standard download, update, and basic crash telemetry as governed by the Microsoft Privacy Statement. We do not have access to individual user identities from Microsoft Store metrics.

6. Security & Encryption

We prioritize security for developer and embedded workflows:

  • Zero Data Transmission: All data, payload contents, and configuration files remain strictly on your local machine and are never transmitted over the Internet.
  • Support for Localhost over TLS: RESTdrop supports secure encrypted communication for localhost over TLS, enabling local API endpoints without plaintext exposure.
  • No Internet Exposure Required: RESTdrop is configured by default to bind to loopback (localhost), preventing unauthorized network inbound access.
  • Sandboxed Webview: The user interface runs within a sandboxed Webview environment with strictly declared IPC capabilities.

7. Children's Privacy

RESTdrop is a technical development and engineering tool intended for software engineers, hobbyists, and test technicians. Because we do not collect any personal information whatsoever, we do not knowingly solicit or collect data from children under the age of 13 (or under 16 in applicable jurisdictions).
